# Code of Conduct

This project follows the Contributor Covenant, version 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful and constructive, assume good faith, and focus
criticism on ideas and code, not people. Report unacceptable behaviour to the
maintainer listed in `DESCRIPTION`. The maintainer will review reports
promptly and confidentially.
